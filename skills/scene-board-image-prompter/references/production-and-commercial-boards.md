# Production And Commercial Boards

## Contents

- Production-design storyboard board
- Commercial segment board
- Ad sequence board
- Design reference board
- Spatial continuity board

## Production-Design Storyboard Board

Create one professional board that locks characters/costumes, props/products, set geography, blocking/movement, camera positions, key beats, and light/material reference.

Use:

```text
hero scene frame
character/model sheet cells
prop/product structure and scale cells
set/location geography
overhead map with positions, paths, eyelines, camera numbers, and axis
4-6 execution beat cards
4-8 preview frames
lighting/material/color strip
```

Do not redesign upstream material or turn the board into a promotional key visual.

## Commercial Segment Board

Translate `source_type` correctly:

```text
tvc/product_demo -> product structure, use, benefit cue, selling scene, brand landing
program_promo -> host/guest/contestant, stage/studio, program object, reveal beat, broadcast landing
event_opener -> theme symbol, stage/LED, ritual action, countdown/reveal, title landing
brand_film -> real people/location, brand proof, chapter emotion, manifesto landing
```

Use a hero panel, locked character/object cells, set/stage geography, a 4-8 beat flow, ending/brand landing, and light/material/color strip. Reserve blank label zones; do not generate final advertising text or logos.

## Ad Sequence Board

Use 6-12 large ordered cells only when `board_type: ad_sequence_board`. Keep character, costume, product/brand object, palette, and visual DNA stable. Each cell shows one clear beat with visible action, framing, object placement, and light. Keep numbering simple and labels blank/sparse.

## Design Reference Board

Prioritize model sheets, costume, hero props/products/program objects, set/stage/location cells, material/color swatches, and 3-6 key visual frames. It is a production guide, not a final poster.

## Spatial Continuity Board

Use a main scene reference, overhead camera map, fixed character/product/prop positions, eyelines, camera directions, 4-6 execution beats, preview cells, and light/material strip. Optimize for preventing disappearance, position drift, wrong eyelines, or changing space.

## Common Source-Prompt Shape

Write a concise natural-language board instruction containing:

```text
board purpose and variant
locked upstream content
large-cell layout and hierarchy
variant-specific control sections
continuity/structure constraints
video inherit/do-not-inherit boundary when applicable
selected content risks
ratio
```

Avoid repeating long explanations for every section. Put exact upstream packet content into the corresponding visual zone.
