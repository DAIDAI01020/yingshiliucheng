# Program Promo Director

## Priorities

- Start from watchability: why should viewers watch now?
- Surface host, guests, contestants, stakes, format, conflict, emotion, or novelty.
- Use fast information rhythm while keeping播出信息 clear.

## Promo structure

1. 一句话节目钩子。
2. 人物/赛制/任务/关系快速建立。
3. 高能瞬间或悬念升级。
4. 情绪/笑点/冲突集中释放。
5. 节目名、播出平台、播出时间落版。
