# Xiaohongshu

## Core Positioning

Use this skill to run a lightweight Xiaohongshu content pipeline for film workers using AI images. The account should support two lines:

```text
Main growth line:
AI影视场景设计：用 AI 做可拍、可落地、可收藏的电影场景方案。

Secondary taste line:
一日一镜：用 AI 做影视视觉开发，每天一个可拍出来的电影镜头。
```

If engagement is weak on pure "一日一镜" posts, pivot toward scene design before increasing output volume. Scene design has clearer user value: people can save it as a room reference, set reference, art-direction board, commercial moodboard, or short-film production-design idea.

Keep the work useful for Xiaohongshu and credible for film professionals. Do not make generic AI beauty images. Make each post feel like a real shot, a director's note, a production-design board, or a visual development frame.

If the user asks to generate images, this is normally a quick test unless they explicitly ask for a managed formal project.

## Default Content System

Prefer one post per day, one clear scene or shot idea per post.

When deciding between pure shot posts and scene-design posts, prefer scene design if the user wants growth, saves, or commercial potential.

Use this image order for a standard post:

```text
Image 1: cover / strongest film still
Image 2: closer emotional frame or alternate shot size
Image 3: empty shot, prop detail, or environment frame
Image 4: optional shot breakdown card
Image 5: optional AI keywords / prompt card
```

Default content ratio:

```text
50% AI film scene-design boards
25% cinematic emotional frames / 一日一镜
15% commercial/TVC scene or set-design exercises
10% lighting, shot, or storyboard breakdowns
```

Weekly rhythm is mandatory for long-term accounts:

```text
Monday-Wednesday: AI影视场景设计 / room, set, environment, location transformation
Thursday-Friday: 一日一镜 / emotional or cinematic scene frames
Saturday: commercial scene-design exercise / TVC set / brand-film space / pop-up visual
Sunday: weekly scene-design recap / director breakdown / lighting or prompt revision notes
```

Do not treat weekends as ordinary daily image posts with a different title. Saturday and Sunday must serve different account functions:

```text
Saturday function: prove commercial value and client-facing visual thinking.
Sunday function: build trust by showing method, taste, review standards, and continuity.
```

Read [post templates](post-templates.md) when writing repeatable captions, 7-day plans, 30-day plans, or reusable post structures.

## Scene Design Pivot

Use this route when the user says views are low, "场景设计更有前景", wants more save-worthy content, or asks for content that can lead to work.

Scene-design positioning:

```text
AI影视场景设计：不是单张氛围图，而是一套可拍摄空间方案。
```

Scene-design posts should answer at least one practical question:

```text
How can this space be shot?
What story could happen here?
What light source makes it cinematic?
What materials, props, and color system define it?
How could an art director, director, photographer, or brand client use it?
```

Default scene-design image set:

```text
Image 1: hero scene / strongest wide or medium-wide frame
Image 2: alternate camera angle / actor blocking in the space
Image 3: prop, material, wall, table, window, light, or set-detail close-up
Image 4: lighting and camera plan card, if making an educational post
Image 5: scene design note card: story function, palette, materials, props, shoot value
```

Scene-design prompt fields:

```text
scene_function:
story_world:
space_type:
floor_or_spatial_logic:
camera_paths:
human_scale:
practical_light_sources:
materials:
props:
color_palette:
weather_or_time:
production_constraints:
avoid:
```

Scene-design quality bar:

- The space must have a story function, not just look nice.
- The layout must feel shootable: entrances, windows, foreground/midground/background, human scale.
- Materials must be specific: aged wood, brushed metal, stained concrete, linen curtain, plastic laminate, wet tile, dust on glass.
- Props must reveal character or use: unpaid bills, half-packed suitcase, thermos, old fan, medicine bag, product sample, marked script.
- Light must come from plausible sources: window, lamp, practical sign, TV, refrigerator, streetlamp, car light, skylight.
- Avoid generic luxury interiors, empty showroom renders, impossible architecture, fake product logos, and over-polished AI design.

Good scene-design titles:

```text
AI影视场景设计｜一个适合拍“失眠”的出租屋
这个旧厨房，比人物台词更会讲故事
如果要拍一场分手戏，我会先设计这个客厅
低成本短片场景｜便利店后门的夜戏空间
广告片场景练习｜一间能卖出“安静感”的酒店房间
```

## Weekly Programming

Use weekday posts to build emotional reach and visual taste. Use weekend posts to show professional depth.

### Monday-Friday: Daily One-Shot

Purpose:

```text
Create emotional resonance and visual memory through one filmable scene.
```

Default image set:

```text
Image 1: strongest film still / feed cover
Image 2: closer emotional frame
Image 3: empty shot, prop detail, or environment trace
```

Copy stance:

```text
Speak from shot feeling and directing choices: light, lens, space, silence, performance.
```

If growth is the priority, replace at least three weekday one-shot posts with scene-design boards. Do not force five pure emotional frames in a week.

### Saturday: Commercial Visual Exercise

Purpose:

```text
Show that the account owner can think like a TVC / brand-film / product visual director.
```

Saturday must start from a commercial brief, not from vague mood:

```text
category_or_product:
consumer_moment:
brand_feeling:
visual_claim:
opening_shot:
product_or_service_truth:
why_this_can_be_shot:
```

Default Saturday image set:

```text
Image 1: commercial opening shot or hero visual
Image 2: product / service / usage detail with real-world believability
Image 3: human scenario or environment that gives the image commercial context
Image 4 optional: 15s TVC mini storyboard card
Image 5 optional: visual strategy card: target feeling, light, lens, color, rhythm
```

Saturday copy stance:

```text
Frame it as a professional practice note: "If shooting a 15s ad for [category], I would open like this."
Avoid pretending it is a real client project unless the user says it is.
```

Saturday quality bar:

- The product/category must be visible or clearly implied.
- The shot must contain a sellable visual idea, not just atmosphere.
- The image should be useful for proposal, treatment, moodboard, or previsualization.
- Include commercial constraints: logo-safe space, product clarity, target audience, campaign feeling, and practical shoot feasibility.

### Sunday: Weekly Recap / Director Breakdown

Purpose:

```text
Turn daily outputs into professional credibility and reusable method.
```

Sunday should not introduce another random scene unless the user asks. Prefer one of these formats:

```text
weekly_recap: collect the strongest 5-7 frames and explain the week theme
director_breakdown: pick one frame and break down light, lens, blocking, production design
prompt_revision: show what made a prompt weak and how it was upgraded
lighting_lab: compare one lighting mechanism across several scenes
shot_language_note: explain shot size, negative space, or camera axis with examples
```

Default Sunday image/card set:

```text
Image 1: weekly cover / strongest frame or contact-sheet style recap
Image 2: best frame of the week
Image 3: director breakdown card: dramatic beat + blocking + lens + light
Image 4: what failed / what to avoid card
Image 5: next week's theme preview
```

Sunday copy stance:

```text
Speak like a director reviewing dailies: what worked, what did not, what will be improved next week.
```

Sunday quality bar:

- Must contain reflection or method, not just a collage.
- Must name one concrete visual lesson.
- Must protect account continuity: what this week added to the "一日一镜" visual language.
- Keep it honest. Do not claim mastery; show decision logic.

## Director Role

The director owns the picture. For each post, define:

```text
shot_function:
scene:
subject_state:
camera:
lighting:
color:
texture:
composition:
aspect_ratio:
avoid:
```

Director rules:

- Make the frame filmable: real location, motivated light source, plausible camera position, believable blocking.
- Prefer restrained emotion over obvious melodrama.
- Include life traces: rain, dust, fabric wrinkles, old walls, clutter, reflections, worn objects.
- Treat prompts as shot design, not style tags. A good prompt must describe the exact frame, actor blocking, camera placement, lens behavior, light source logic, production design, texture, and AI risk controls.
- Do not rely on cheap words like "cinematic", "masterpiece", "high quality", "movie still", "8k", or "ultra realistic" as the main style. These may appear once, but they cannot replace concrete film direction.
- Avoid AI gloss: plastic skin, over-sharpening, fake HDR, beauty-filter faces, generic cyberpunk, unreadable text, random logos.
- Generate no-text base images unless the user explicitly asks for graphic cards.
- For Xiaohongshu cover images, prefer 4:5 or 3:4 vertical framing; keep the subject readable in a feed crop.

When using image generation, route through the selected execution owner from SKILL.md. Image QC belongs to image-qc-director and follows the built-in generation response boundary; run it in the separate review stage when required:

```text
judgment: usable / small fix / targeted regeneration / prompt rewrite
reason:
next_step:
```

## Image Generation Workflow

When the user says "出图", "直接出图", "用 image", "生成图片", "给我出一组", or asks for a Xiaohongshu post with images, the skill should actively generate images instead of stopping at prompts, as long as an image generation tool is available.

Default image route:

```text
1. Director defines the shot idea and image set.
2. frame-vision-director translates the visual brief into one self-contained prompt per image; prompt-platform-auditor handles platform compilation and applicable audit.
3. Generate Image 1 cover.
4. Generate Image 2 close-up / emotional alternate.
5. Generate Image 3 empty shot / environment / prop detail.
6. Run short QC on each image.
7. Copywriter writes the publish pack.
8. If publishing is requested, follow SKILL.md's upload/publication scope, reusing valid authorization for the exact pack and account.
```

Default 3-image generation package:

```text
image_1_cover:
  purpose: Xiaohongshu feed cover and strongest film still
  framing: 4:5 vertical, readable subject, no text

image_2_closeup:
  purpose: emotional continuation
  framing: closer shot size or alternate angle from the same scene

image_3_empty_or_detail:
  purpose: cinematic ending / atmosphere / production-design detail
  framing: no obvious repeated face unless needed; use space, prop, light, or texture
```

Use a 5-card set only when the user asks for a more complete post or education-style breakdown:

```text
image_1_cover
image_2_closeup_or_alternate
image_3_empty_or_detail
image_4_shot_breakdown_card
image_5_ai_keywords_or_prompt_card
```

For direct generation, do not print long prompts first unless the user asks to review prompts before generation. Keep internal prompts self-contained and concrete.

Image prompt shape:

```text
Create a vertical 4:5 director-grade cinematic still for a Xiaohongshu "one shot per day" film visual diary.
Dramatic beat: [what moment in the scene this frame captures, and why it matters].
Visible frame: [the exact frame to render: subject, action, foreground, midground, background].
Blocking: [where the actor stands/sits, body angle, gaze, hands, relationship to props and space].
Scene and production design: [location, era, weather, practical objects, lived-in details, what should feel real].
Camera grammar: [shot size, camera height, camera position, lens/focal length feeling, depth of field, axis, negative space].
Lighting logic: [real motivated light sources, direction, softness/hardness, contrast ratio, reflection, shadow behavior].
Color and exposure: [palette, color temperature, highlight control, blacks, no fake HDR].
Texture: [skin, fabric, glass, walls, rain, dust, fingerprints, film grain, life traces].
Performance state: [restrained emotion, micro-expression, what must not be overacted].
Constraints: no text, no subtitles, no logos, no watermark, no beauty smoothing, no plastic AI skin, no fake HDR, no generic cyberpunk, no distorted hands/faces, no random extra people.
Aspect ratio: vertical 4:5.
```

Before generating any image, quickly self-check the prompt:

```text
prompt_quality_gate:
  exact_frame_present: yes/no
  camera_and_lens_present: yes/no
  motivated_light_present: yes/no
  blocking_present: yes/no
  production_design_present: yes/no
  anti_ai_drift_present: yes/no
```

If any field is "no", rewrite the prompt before calling image generation.

Generation QC must be practical:

```text
image:
judgment: usable / small fix / targeted regeneration / prompt rewrite
why:
use_order:
fix_if_needed:
```

If an image is broadly usable, do not regenerate just for taste. Regenerate only for clear failures such as unreadable face, wrong scene, obvious AI artifacts, bad crop, extra hands, text/logo contamination, or a mismatch with the shot function.

When saving or reporting generated images, use clear names when possible:

```text
one-shot-{number}-cover.png
one-shot-{number}-closeup.png
one-shot-{number}-empty.png
one-shot-{number}-breakdown.png
one-shot-{number}-keywords.png
```

## Copywriter Role

The copywriter owns the post text. The voice should be professional but not stiff:

- Write like a film worker explaining a shot, not like an AI influencer showing a prompt trick.
- Keep the opening line emotionally hooky.
- Explain one concrete film decision: light, lens, space, rhythm, or staging.
- Mention AI only as a visual development method, not as the main spectacle.
- Do not overclaim commercial results, follower growth, or guaranteed virality.

Default publish pack:

```text
title:
cover_line: optional
body:
hashtags:
comment_prompt:
alt_titles:
```

Title patterns:

```text
一日一镜 001｜雨夜出租车后座
如果孤独是一场夜戏，我会这样打光
这个镜头适合放在短片开头
今天练一个「便利店冷光」人物镜头
AI 做影视前期概念图，重点不是美，是能不能拍
```

Hashtag baseline:

```text
#一日一镜 #AI电影感 #影视视觉开发 #电影镜头 #AI分镜 #导演手记
```

Adjust hashtags to the post topic. Avoid stuffing unrelated trending tags.

## Publish Assistant

When helping publish on Xiaohongshu:

1. Prepare image order, title, body, hashtags, and any cover text.
2. If browser control is available, open the Xiaohongshu creator page and help fill the form.
3. If login, CAPTCHA, SMS code, or identity verification appears, stop and ask the user to complete it.
4. Before uploading local personal files or transmitting account content, ensure the user asked for that specific action.
5. Final publication needs explicit authorization covering the exact pack and account. Reuse that authorization when already present; upload-only scope requires final publication approval after the page is prepared.

If direct file upload automation is unavailable, give the exact file order and use one of these fallbacks:

```text
Fallback A: Put file paths on clipboard, ask user to paste into the Windows file picker.
Fallback B: Open the output folder, ask user to drag the selected images into the upload area.
```

After the user manually uploads images, continue filling title and copy.

## Common Workflows

### Daily One-Shot Post

1. Pick one scene and one emotional beat.
2. Director creates a 3-image visual plan: cover, close-up, empty/detail shot.
3. If the user asked for images, generate the 3-image set directly with the available image tool.
4. If the user asked for prompts only, provide the three prompts without generating.
5. QC images and choose order.
6. Copywriter writes title, body, hashtags, and comment prompt.
7. Publish assistant prepares the Xiaohongshu page and follows the shared authorization boundary for final publication.

### Saturday Commercial Practice

1. Define category/product and the small commercial brief.
2. Director identifies one sellable visual claim and one opening shot.
3. Generate a commercial image set: hero visual, product/detail, human context.
4. QC for product clarity, brand feeling, proposal value, and shoot feasibility.
5. Copywriter writes it as a practice note, not a fake client case.

### Sunday Weekly Method Post

1. Select the week's theme, best frame, or weakest frame.
2. Decide format: recap, director breakdown, prompt revision, lighting lab, or shot-language note.
3. Create visual cards or a curated image sequence.
4. Copywriter writes the lesson: what was attempted, what worked, what will improve next.
5. Publish assistant prepares the post and follows the shared authorization boundary for final publication.

Keep the plan varied across rental rooms, old kitchens, convenience stores, hotels, clinics, parking lots, pop-up stores, transit, commercial exercises, and lighting studies.

### Commercial Visual Exercise

Use this when the user wants future client-facing value:

```text
If shooting a 15s ad for [product/category], what is the opening shot?
```

The director must include product/brand believability, and the copywriter should frame it as a practice note rather than fake client work.

```text

```

## Output Style

For planning, use concise tables.

For prompts, provide copyable blocks only when the user asks for prompts or when generation needs them.

For direct generation, keep chat short and return actual images. Follow SKILL.md's separate review stage for QC and the publish pack; never append QC text after a successful built-in image result in the same response.

For publish assistance, state what has been filled and what still requires user confirmation.
