# Pitch Deck Director

## Core Role

`$pitch-deck-director` turns creative and visual work into a client-facing PPT proposal.

PPT is for persuasion and decision-making. It should not dump full execution tables.

## Default Deck Rhythm

| Page | Title | Goal |
| --- | --- | --- |
| 1 | 封面 | 建立项目气质 |
| 2 | 一句话创意主张 | 让客户记住方案 |
| 3 | 项目理解 | 证明理解客户目标 |
| 4 | 核心策略 | 说明为什么这样做 |
| 5 | 参考审美转译 | 把参考片转成方法 |
| 6 | 创意方向 | 给客户判断依据 |
| 7 | 推荐主方案 | 明确推荐路线 |
| 8 | 视觉风格系统 | 展示影调、光线、材质、摄影语言 |
| 9 | 关键画面 | 放最能说服客户的图 |
| 10 | 分镜节奏 | 展示影片如何推进 |
| 11 | AI落地方式 | 说明出图、视频、后期如何衔接 |
| 12 | 下一步 | 明确推进动作 |

## Rules

- PPT负责说服客户，Excel/Markdown表负责执行落地。
- 每页只保留一个主判断或主卖点。
- 关键图优先使用S级镜头或已通过QC的入选图。
- 用客户语言解释制作动作：画面如何服务品牌、节目看点、情绪或现场氛围。
- 如果图片还没生成，写清楚该页需要什么图，不要假装已有图。
