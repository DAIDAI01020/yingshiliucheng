## Purpose And Boundary

This file supplies real studio/case mechanisms for commercial KV, product key art, event main visuals, launch visuals, program packaging, banners, and cinematic base art.

It supplements `$kv-director`; it does not replace `kv-composition-style-library.md`. Use this file to answer “which proven case mechanism fits?”, then let `$kv-director` decide composition hierarchy, safe areas, typography relationship, crop behavior, and extensions.

Narrative film posters, short-drama character posters, and story key art still route to `$poster-director`. When a commercial KV uses cinematic base art, this library may provide the case system while `film-prestige-visual-library.md` provides the image-world mechanism.

## How To Use

Choose:

```text
1 primary case mechanism
0-2 supporting mechanisms
1 kv_composition_mode from kv-director
1 primary_style_family from kv-director
```

Never reproduce a campaign layout, logo, custom typeface, product geometry, character, or signature object. Translate the case into hierarchy, material, light, modularity, motion behavior, and deliverable logic.

KV admission is evidence-led: an entry needs an official studio/brand case source, a distinct transferable system mechanism, and a clear `do_not_copy` boundary. Pinterest, Behance, Dribbble, awards, likes, or visual popularity may help discovery but cannot by themselves qualify a case for the core library. Remove or merge cases that add only another surface style without a new communication, layout, material, motion, or extension mechanism.

```text

```

Hard rules:

- Case selection never overrides brand truth, product geometry, approved claim, screen dimensions, or title/logo authority.
- Use one primary case and at most two supporting cases.
- The final prompt contains mechanisms and layout constraints, not studio/campaign names.
- All exact text, logos, sponsor marks, and final typography remain a post-layout or exact-type asset task unless the selected image platform is explicitly approved for exact text.
