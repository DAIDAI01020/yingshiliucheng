# Short Drama / Story Visual Reference Library v1

Use for short drama, micro-series, vertical drama, suspense, family, romance, revenge, and character-driven narrative workflows.

This library upgrades short-drama visuals away from cheap web-drama habits. It uses top-tier cinema and prestige series as the reference standard, then translates them into scene-level AI generation rules.

## Selection Rule

For one short-drama project, choose:

- 1 primary story-visual system for the whole series
- 1-2 scene-specific reference systems
- 1 performance/blocking principle for main characters

Do not mix too many auteur styles. Short drama needs consistency, readable emotion, and stable character continuity more than reference variety.

If the user provides no reference images, actively recommend a primary story-visual system from this library and one cinematography anchor from `shared-elite-cinematography.md`. Do not wait for the user to supply references before establishing a professional visual floor.

If the user provides reference images, analyze the images first, then match them to the closest mother-library visual mechanism. Do not simply copy the reference image style. State:

```text
参考图可继承什么
匹配到的母库机制
需要转译成哪些摄影/光线/空间规则
不能继承什么
```

Every formal short-drama handoff must translate the chosen mother-library mechanism into these fields:

```text
光线方向 + 空间关系 + 焦段心理效果 + 构图调度 + 材质触感 + 人物表演状态 + AI风险控制
```

Do not output only `电影感`、`高级感`、`真实感`、`低饱和`、`某导演风格`. These are labels, not executable visual mechanisms.

## Vertical Short-Drama Execution Logic

| Scene function | Better reference logic | AI prompt requirement |
| --- | --- | --- |
| 开场钩子 | strong spatial question, immediate visual symbol, readable tension | one clear object/action, no crowded exposition |
| 报案/求助 | institutional threshold, anxious blocking, cold practical light | police desk/door/window as pressure point |
| 对质 | over-shoulder geometry, controlled distance, face tension | two-person blocking, eye-line clarity, no extra characters |
| 审讯 | fluorescent pressure, glass reflection, long-lens compression | trapped composition, face and hands visible |
| 监控/手机/文件 | screen glow as atmosphere, unreadable text, evidence framing | do not request accurate text; use shapes, numbers, blurred documents |
| 闪回 | changed light/time/material, subjective camera, no cheap dream filter | use color temperature and texture change, not fantasy blur |
| 犯罪现场 | mud, dust, fabric, metal, water; avoid gore spectacle | object clues and environment, not graphic violence |
| 情感崩溃 | closer lens, shallow depth, restrained performance | one emotional beat, no exaggerated tears |
| 反转 | reveal spatial/object relation, not only dramatic lighting | camera reveals hidden object/person relation |
| 收束 | calmer frame, more air, lower contrast, moral aftertaste | less visual noise, more negative space |

## Character Continuity Rules

Use for AI image/video generation:

```text
Character continuity comes before scene decoration.
Each main character needs stable: face age range, hairstyle, body type, wardrobe anchor,
color anchor, emotional baseline, and forbidden changes.
Do not change face structure, costume logic, or relationship blocking unless the script demands it.
```
