## Purpose

Use this library for film, prestige-series, brand-film, city-film, cultural-film, narrative KV base art, and formal multi-scene work that needs a stronger cinematic reference system.

This is a mechanism library, not a title list. Select references by project function and translate them into visible controls. Never ask an image or video model to imitate a living artist, a director, a cinematographer, or an exact copyrighted frame.

Cross-reference rules:

- Use `shared-elite-cinematography.md` for the mandatory camera/light anchor in formal live-action work.
- Use `short-drama-story-library.md` when the task is specifically vertical drama, serialized conflict, or scene-by-scene dramatic mechanics.
- Use this file when the project needs broader film/prestige-series world logic, architecture, scale, culture, documentary truth, or genre atmosphere.

## ShotDeck-First Quality Gate

[ShotDeck](https://shotdeck.com/) is the preferred shot-level discovery and comparison interface when the user has access. It is useful because images are searchable through craft dimensions including crew, camera/lens, framing, lighting, color, composition, location, and performance emotion. The mother library should behave the same way even when ShotDeck access is unavailable.

ShotDeck inclusion alone is not an approval badge. ShotDeck intentionally covers cinema history, diverse filmmakers, countries, user requests, music videos, commercials, series, and visually iconic work. A title enters this mother library only when specific shots provide repeatable craft mechanisms for the user's production needs.

Score every proposed addition from 0-5 on six dimensions:

| gate | question |
| --- | --- |
| cinematography_distinction | Is there a clear and defensible camera/light/color/space decision rather than generic polish? |
| shot_level_retrievability | Can the useful mechanism be found through concrete shot attributes instead of a vague whole-film label? |
| transferability | Can the mechanism be rewritten as visible prompt or production controls? |
| functional_coverage | Does it solve a project function not already covered better by an existing entry? |
| craft_evidence | Can it be checked in ShotDeck, an official cinematography source, or a high-quality official production source? |
| anti_copy_safety | Can the mechanism be separated from actor likeness, protected design, exact framing, and plot/IP? |

Admission rule:

```text
Core A: score >= 25/30 and no gate below 3
Specialist B: score >= 21/30, used only for its named specialist function
Watchlist: score < 21 or evidence incomplete; never used in a formal recommendation
Duplicate: adds no new mechanism; reject even when the title is famous
```

For rows whose source is `现有母库策展索引`, formal use requires a task-time ShotDeck check or an official cinematography/production source check. Do not claim a ShotDeck frame was inspected unless it was actually opened in the user's authenticated session.

ShotDeck retrieval should start from the shot need, not the film title:

```text
project_function
-> subject_and_action
-> framing_and_camera_angle
-> lighting_source_and_quality
-> color_relationship
-> composition_and_depth
-> location_production_design_material
-> performance_emotion
-> camera_lens_or_format when it materially matters
-> shortlist 8-12 shots
-> keep 3-5 mechanism-distinct shots
-> translate to one project rule and scene-specific controls
```

ShotDeck images are reference/research material. Store links, deck IDs, and analysis notes; do not republish or use the images as final commercial assets. See ShotDeck's [usage guidance](https://help.shotdeck.com/content/how-can-i-use-the-images-on-shotdeck/).

## Selection Method

Choose:

```text
1 primary reference = controls the project DNA
0-2 secondary references = each solves one named scene or communication problem
1 cinematography anchor = controls camera/light discipline when applicable
```

Each selected row must be translated through:

```text
project function -> transferable mechanism -> prompt-visible controls -> do_not_copy
```

Do not mix entries only because they are famous. Do not combine references whose realism level, performance style, color logic, or spatial rules conflict.

When ShotDeck is available, record the actual deck or shot links used. When it is unavailable, return a `shotdeck_search_recipe` rather than pretending that the frames were checked.
