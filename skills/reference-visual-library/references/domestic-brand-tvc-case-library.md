# Domestic Brand TVC Case Library v1

Use this file as a case index for China-related technology, appliance, smart-home, automotive, and export-market TVC references.

This is not a prompt library and not a brand-asset copying library. Do not copy logos, slogans, product design, celebrity likeness, music, exact scripts, exact layouts, or proprietary campaign ideas. Use each case only to extract executable visual mechanisms for `$style-reference-director`, `$style-bible-director`, `$frame-vision-director`, and `$ai-video-prompt-director`.

## Case Use Rule

For one commercial project, pick:

- 1 case family that matches the product category
- 1 visual mechanism from the case
- 1 shared cinematography anchor from `shared-elite-cinematography.md`
- 1 platform risk note for image/video generation

For new case records, use this structure:

```text
case_name:
brand:
category: phone / smart_device / EV / appliance / smart_home / screen / export_tvc / food_freshness
source_url:
verified_date:
usable_mechanism:
not_for:
downstream_translation:
ai_risk_control:
```

Never stack brand names in final prompts. Final prompts must translate cases into:

```text
light direction / practical source
space relationship / product-to-human scale
lens and camera behavior
material and surface truth
human performance or hand interaction
function visualization
AI risk controls
```

## AI Risk Controls

```text
Do not use real brand logos unless user owns/provides them.
Do not request exact product design unless it is supplied as a reference image.
Do not invent readable UI text.
Do not copy slogan, campaign title, celebrity face, music, or exact plot.
For product video, lock product structure, scale, material, wheel/part size, and logo placement from the provided reference image.
For appliance function, show cause-effect through real environment response, not fake particles, holograms, CG airflow, or platform template effects.
```
