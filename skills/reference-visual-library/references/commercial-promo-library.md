# Commercial / Promo Visual Reference Library v1

Use for brand films, corporate films, city films, TVC, product ads, event openers, LED visuals, program packaging, and social cutdowns.

This library is not a name-dropping list. Each reference must be translated into practical visual rules before prompt writing.

For China-related product, appliance, smart-home, phone, vehicle, and export-market TVC case records, also check:

```text
domestic-brand-tvc-case-library.md
```

Use those records as lookup examples only. Do not copy brand assets; translate Xiaomi, Haier, Midea, Huawei, Hisense, Gree, and similar cases into camera, light, product scale, function visualization, material truth, and AI risk controls.

## Selection Rule

For one project, choose:

- 1 primary reference family
- 1 cinematography anchor if needed
- 0-2 secondary references for scene-specific needs

Do not stack many famous references inside one prompt. Convert them into concrete style language.
