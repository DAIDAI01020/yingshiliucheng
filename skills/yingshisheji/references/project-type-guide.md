# Project Type Guide

## TVC广告

Focus on product benefit, brand memory, rhythm, and clear call-to-action. Typical structures:

- Problem to solution
- Sensory product showcase
- Brand attitude
- Scene usage montage
- Product reveal and slogan

## 品牌片 / 城市片 / 企业形象片

Focus on values, trust, scale, people, and long-term identity. Use a stronger narrative arc than TVC:

- 起：时代/问题/愿景
- 承：行动/技术/人群/场景
- 转：突破/连接/价值证明
- 合：品牌主张/未来愿景

## 电视节目宣传片 / 栏目包装 / 综艺预告

Focus on watchability: concept, cast/host, conflict,赛制,情绪,笑点,悬念,播出信息.

Use sharper hooks:

- 一句话节目钩子
- 人物关系或看点
- 赛制/任务/冲突
- 高能瞬间
- 播出信息收束

## 发布会 / 盛典 / 论坛开场片

Focus on ceremony, theme reveal,现场气势, brand or event identity, and transition into host/stage.

Structure:

- 空间或时代开篇
- 主题逐步显影
- 行业/品牌/人物能量聚合
- 主KV或主题字落版
- 舞台灯光/主持人衔接点

## LED大屏 / 舞美视觉

Focus on scale, readability, spatial immersion, and rhythm with现场表演.

Always consider:

- 屏幕比例和分辨率
- 主视觉中心安全区
- 舞台人物和屏幕内容的关系
- 分屏、异形屏、折角屏、地屏风险
- 远距离观看时的文字和主体大小

## 社媒切条

Focus on dramatic intent, character relationships, source continuity and the specified delivery format. Support 16:9 landscape, 9:16 portrait and custom ratios. Inherit runtime and viewing context; vertical composition and a first-three-seconds hook apply only when appropriate to the project.

Adapt the master idea into:

- 预热视频
- 倒计时短片
- 竖版片段
- 金句卡点
- 幕后或花絮包装
