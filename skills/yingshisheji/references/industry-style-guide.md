# Industry Style Guide

Use this when the project belongs to a clear industry and the user has not specified a style.

| 行业 | 推荐主风格 | 视觉关键词 | 摄影/AI建议 |
| --- | --- | --- | --- |
| 汽车 | 高级速度电影感 | 车身线条、道路空间、反射、速度、科技座舱 | Sony Venice 2 or RED V-Raptor, low tracking, controlled reflections |
| 美妆护肤 | 柔光微距高级感 | 肌肤、光泽、水感、花材、干净背景 | ARRI Alexa Mini LF, 100mm macro, soft beauty light |
| 食品饮料 | 食欲质感生活感 | 热气、咀嚼感、液体、家庭/朋友、鲜活色彩 | ARRI Alexa 35, macro detail, warm side light |
| 科技发布会 | 极简科技仪式感 | 产品轮廓、黑白灰空间、数据、结构、精准光 | Apple-like minimal launch method, not direct imitation |
| 文旅城市 | 情绪叙事与城市人文 | 航拍、街巷、人物、烟火气、地标、日夜变化 | Alexa Mini LF, Cooke warmth, dawn/dusk light |
| 地产空间 | 空间秩序与生活想象 | 建筑线条、家庭、景观、晨昏、材质 | wide lens, smooth dolly, premium natural light |
| 金融/商务 | 稳健可信高级感 | 城市、玻璃、秩序、人物、数据、信任 | clean commercial lighting, restrained color |
| 教育/公益 | 纪实人文温度 | 真实人物、课堂、陪伴、成长、手部细节 | natural light, documentary restraint, warm color |
| 综艺/节目 | 高能包装与人物看点 | 人物关系、赛制、冲突、笑点、舞台、字幕 | Angenieux Optimo, dynamic zoom, bold graphic light |
| 晚会/发布会 | 仪式开场大片感 | 倒计时、主KV、光束、粒子、主题字、舞台衔接 | anamorphic scale, center-safe LED composition |

## Usage

1. Pick the industry row that best matches the brief.
2. Combine it with project type and viewing context.
3. Recommend one main style and two backup options.
4. For AI prompts, convert the row into camera, lens, lighting, material, motion, and negative prompts.
