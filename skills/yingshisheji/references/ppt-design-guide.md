# PPT Design Guide

Use this when `$yingshisheji` needs to design a client-facing film, TVC, program promo, event opener, or large-screen visual proposal.

## Core principle

PPT is for persuasion. Excel is for execution.

The PPT should not show every storyboard row or every prompt. It should help the client understand:

- What is the idea?
- Why is this the right style?
- What will the film/screen feel like?
- What are the strongest key frames?
- Why should this route be approved?

## Default deck structure

| 页码 | 页面 | 页面目标 | 内容 |
| --- | --- | --- | --- |
| 1 | 封面 | 建立项目气质 | 项目名、主题句、项目类型、版本 |
| 2 | 一句话创意主张 | 让客户记住方案 | 1句核心概念 + 1段短解释 |
| 3 | 项目理解 | 证明理解需求 | 目标、受众、核心信息、观看场景 |
| 4 | 稿件气质判断 | 说明风格从哪里来 | 稿件气质、推荐主风格、备选风格、不建议方向 |
| 5 | 参考风格拆解 | 借势但不照搬 | 参考对象、可借鉴方法、本项目转译、避免照搬 |
| 6 | 创意方向总览 | 给客户选择感 | 2-3个方向，明确推荐主方案 |
| 7 | 推荐主方案 | 聚焦最强路线 | 主题命名、叙事逻辑、视觉关键词、推荐理由 |
| 8 | 视觉风格板 | 建立画面想象 | 色彩、光影、摄影系统、镜头语言、材质 |
| 9 | 叙事结构 | 说明片子怎么推进 | 起承转合、时间段、情绪曲线 |
| 10 | 关键画面 1 | 展示视觉记忆点 | 画面描述、客户话术、出图方向 |
| 11 | 关键画面 2 | 展示情绪或产品价值 | 画面描述、客户话术、出图方向 |
| 12 | 关键画面 3 | 展示高潮或落版 | 画面描述、客户话术、出图方向 |
| 13 | AI视觉生成策略 | 解释AI如何服务方案 | 出图优先级、三套风格、风险控制 |
| 14 | 落地流程 | 让客户放心可执行 | 确认方向、关键帧、动态测试、执行表 |
| 15 | 下一步 | 推动确认 | 需要客户确认的事项 |

For a short proposal, compress to 8 pages: 封面、创意主张、项目理解、风格判断、参考拆解、推荐方案、关键画面、下一步。

## Slide output format

When generating PPT content, use this structure:

| 页码 | 标题 | 页面目标 | 页面文案 | 画面/版式建议 | 适合放的图 | 讲稿备注 |
| --- | --- | --- | --- | --- | --- | --- |

## Layout language

Use these page patterns:

- Full-bleed key visual: for cover, key frame, emotional climax, LED or event opener.
- Split reference analysis: left reference method, right project translation.
- Three-route comparison: use only for creative direction, not for every section.
- Style board grid: color, light, lens, texture, motion, typography.
- Timeline strip: for script rhythm and story structure.
- Hero frame + caption: for key storyboard pages.
- Before/after logic: for script diagnosis or reference translation.

## Visual hierarchy

- One page should make one point.
- Page titles should be proposal language, not file labels. Use `让产品像舞台主角一样被揭示`, not `视觉风格页`.
- Keep body copy short: 1 title, 1 short explanation, 3-5 bullets maximum.
- For key frame pages, image is the hero. Text should support, not compete.
- Use client-facing meaning beside production language.

## Proposal tone

Prefer language like:

- `我们建议以极简科技发布会质感建立产品的主角感。`
- `镜头不急于展示全部信息，而是通过轮廓光和缓慢推进制造期待。`
- `这个画面承担的是记忆点，而不是单纯的过场。`
- `视觉上保持克制，让客户第一眼感到高级、可信、可落地。`

Avoid:

- Long paragraphs.
- Too much execution detail on PPT pages.
- Showing all AI prompts in PPT.
- Overusing empty words such as 赋能、焕新、未来感 without visible design choices.

## Reference style examples

### Apple keynote style

PPT should emphasize:

- Minimal black/white/gray space.
- Product or theme as the hero.
- Precise rim light and contour.
- Slow reveal logic.
- Few words, high confidence.

Suggested slide titles:

- `让主题像产品发布一样被揭示`
- `用克制空间建立高级感`
- `少即是多：把注意力集中到核心信息`

### Program promo style

PPT should emphasize:

- Watchability, hooks, high-energy moments.
- Character or host appeal.
- Conflict, task, format, or reveal.
- Broadcast readability.

Suggested slide titles:

- `前三秒建立节目钩子`
- `用人物关系制造观看理由`
- `把高能瞬间转成视觉记忆点`

### LED/event opener style

PPT should emphasize:

- Ceremony, scale, stage transition.
- Screen ratio and center-safe composition.
- Theme reveal and live atmosphere.
- Motion that supports the stage moment.

Suggested slide titles:

- `从空间进入主题`
- `让主KV在现场完成一次揭幕`
- `画面为舞台服务，而不是抢舞台`
