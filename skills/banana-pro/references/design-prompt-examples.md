# 设计类提示词：内置 image / Banana 对照范例

## 使用边界

这些是原创演示 brief，供提示词适配与未来同题测试使用，尚未经过实图对比验证。它们不构成生成授权，也不是任何正式项目的已批准方案。

先由对应的 KV、海报、场景或画面导演确定创意，再由 prompt-platform-auditor 转译。本文件帮助把设计决策写成可见画面要求，不新增创意审批或生成入口。Banana 实际调用仍归 banana-image-generator；内置 image 沿用现有流程。

整体出图覆盖不同视觉语言，按项目选择。小红书项目的“异世界巨构＋电影感光线”只在该项目明确要求时使用；不扩散为 KV、产品广告、场景和海报的统一预设。

## 适配方法

- 保持同一创意：两版的主体、概念、构图、配色、文字、参考图职责一致；可调整句式，不暗改设计。
- 把审美写具体：“高级”要落实为形状比例、留白分配、视觉层级、材质差异和光线秩序。避免只堆“顶级、大片、8K、获奖”。
- 按任务取字段：平面 KV 先写信息层级与形状；产品先写结构与材质；场景先写空间与光源；概念海报先写一个鲜明视觉隐喻。非摄影任务无需镜头参数。
- 参考图必须真实存在。产品图只管结构/身份，构图参考只管布局，光色参考只管光色；明确不继承的文字、品牌、人物或背景。没有参考图时，概念产品不得宣称与真实商品精准一致。
- 需要文字时写清逐字内容、位置与主次；不需要文字时明确保留排版区。不要把所有 KV 都默认做成无字底图。
- 网站手动使用时，只复制提示词正文，按界面可用选项设置画幅。不要把 OpenRouter 参数或 Midjourney 后缀粘入正文。

## 1. 品牌 KV：声音变成可见的形状

演示 brief：虚构声音艺术节的横版主视觉，无字底图；16:9。重点是一个可识别图形和清晰的后期排版区。

### 内置 image

```text
设计一张声音艺术节的 16:9 横版主视觉底图。暖白色背景上，用一条钴蓝色纸带折出一个抽象的声波环，作为唯一主体，位于画面右侧约六成区域。纸带连续完整，外轮廓简洁，只有几处大幅折转；纸的厚度、折边和投影清楚，既像雕塑又能一眼读成有节奏的平面符号。左侧约三分之一保留完整暖白留白，供后期排标题，纸带和投影均不进入这一区域。光从左上方柔和照下，阴影轻薄，背景无纹理。只用钴蓝和暖白，视觉重点在轮廓、负空间与折面深浅。画面没有文字、标志、装饰小图标或额外纸带。
```

### Banana

```text
生成一张 16:9 声音艺术节主视觉底图，设计核心是“一条纸带形成可见的声波”。暖白背景，唯一主体为钴蓝色纸带折成的抽象声波环。
版式：主体位于右侧约六成区域；左侧约三分之一是连续、干净的暖白排版留白，主体与投影都不侵入。纸带外轮廓简洁，用少量大幅折转建立节奏，不堆叠细碎褶皱。
形体：纸带连续完整，具有真实纸张厚度和清晰折边；保留环内部的负空间，远看是明确的图形，近看才看到折面结构。
光色：左上方柔光形成轻薄投影，仅以钴蓝折面的明暗区分结构，背景为平整暖白。画面保持钴蓝与暖白两色体系。
输出为无字底图，不生成标题、logo、小图标、第二条纸带或背景纹理。
```

看图检查：缩小后能否读出唯一符号；左侧是否真能排字；折面是否帮助形状而非制造杂乱。

## 2. 产品广告：用材质差异建立价值感

演示 brief：虚构无标识香水瓶的静物广告，4:5。没有输入图，因此是概念产品设计。

### 内置 image

```text
拍摄感的 4:5 竖版香水静物广告。一只无标识的扁矩形透明玻璃香水瓶，厚玻璃底，内装浅琥珀色液体，配短圆柱拉丝银色瓶盖，直立在浅灰石灰岩台面上。瓶子位于画面中央略偏下，占画面高度约一半，上方保留安静的灰白空间。以接近瓶身中部高度的轻微侧前方视角观看，瓶身正面与一侧同时可见，垂直边线保持端正。左侧大面积柔光在玻璃边缘形成受控的亮线，右侧较暗，体现瓶壁厚度与液体折射；瓶盖的细密拉丝反射比玻璃更柔和。石材只保留少量自然孔隙，接触阴影可信，背景平滑。焦点覆盖完整瓶身与瓶盖，不用强虚化掩盖结构。没有文字、植物、飞溅、烟雾、额外瓶子或夸张星芒。
```

### Banana

```text
生成一张 4:5 竖版香水静物广告，主角是一只原创无标识概念香水瓶。
产品结构：扁矩形透明玻璃瓶，厚玻璃底，浅琥珀色液体，短圆柱拉丝银色瓶盖；整只瓶子直立，结构完整，没有标签或文字。
构图与视角：瓶子居中略偏下，占画面高度约一半，上方保留干净灰白空间。相机高度接近瓶身中部，从轻微侧前方观察，同时看到正面和一侧；瓶体垂直线端正，完整瓶身和瓶盖均清晰。
材质与光线：浅灰石灰岩台面仅有少量自然孔隙。左侧大面积柔光在玻璃边缘形成窄而受控的亮线，右侧明度较低；透明瓶壁厚度、液体与玻璃的折射可区分。金属瓶盖呈细密拉丝与柔和反射，不能与玻璃呈现相同表面质感。瓶底与台面有可信接触阴影，背景平滑安静。
只保留这一只瓶子和台面，不添加文字、植物、飞溅、烟雾、星芒或额外产品，不用强景深虚化隐藏瓶体结构。
```

真实产品改写：将上述虚构结构替换为已核对的产品参考信息，在两版中同样声明“输入图1仅控制产品外形、比例、瓶盖、标签和颜色；不继承其背景与布光”。只有用户确实提供图1时才能使用此句；已有标签不得继续写“无标识”。

看图检查：产品轮廓、比例、瓶盖是否正确；玻璃、液体、金属、石材是否具有不同的受光行为。

## 3. 场景设计：以空间和光源组织气氛

演示 brief：海边旧气象站改造的阅读室空镜，16:9；安静、可信的生活尺度。

### 内置 image

```text
生成一张 16:9 的建筑室内场景图：海边旧气象站改造成的小型阅读室。视点在入口附近，眼平高度，以适度广角看向房间尽端的方形海景窗，建筑垂直线自然端正。前景左侧只露出一段深色木书架边缘；中景是一张有使用痕迹的长木桌和四把椅子，桌椅之间留出真实可通行的距离；后景窗外是阴天的灰蓝海面和清晰水平线。墙面是暖灰矿物涂料，地面为深灰石材。窗户的冷色散射天光是主要照明，沿桌面和地面向入口逐渐衰减；桌上一盏小台灯只照亮附近一小块纸面，不照亮整间房。墙角、桌脚和书架深处保留自然暗部，不做均匀提亮。表现木材触感、涂料细微颗粒和可信的空间深度。无人，没有光束、浓雾、巨型建筑或超现实装饰。
```

### Banana

```text
生成 16:9 建筑室内空镜：一间由海边旧气象站改造的小型阅读室，尺度适合日常使用，氛围安静。
空间与机位：从入口附近以眼平、适度广角看向房间尽端的方形窗，建筑垂直线自然端正。前景左侧仅有一段深色木书架边缘；中景为一张旧长木桌和四把椅子，椅子与通道之间保留可通行距离；后景是方形海景窗，窗外阴天灰蓝海面，水平线清晰。
材质：暖灰矿物涂料墙，深灰石材地面，木桌有轻微使用痕迹，书架为深色木材；表面纹理细微且比例真实。
照明：窗外冷色散射天光是主光，由窗边向入口自然衰减。桌上只有一盏小台灯，暖光只覆盖附近一小块纸面。墙角、桌脚与书架深处保留暗部，用明暗衰减交代空间纵深。
场景中没有人物。保持室内尺度与光源可信，不添加光束、浓雾、巨型建筑、超现实装饰，不将室内各处均匀提亮。
```

看图检查：前中后景是否成立；桌椅尺度和通道是否可用；每个亮部是否有可信光源。此范例不规定其他场景必须走写实或安静路线。

## 4. 概念海报：一个隐喻支撑整张画面

演示 brief：虚构悬疑片《静音证词》，2:3，有标题；丝网印刷风格平面海报。

### 内置 image

```text
设计一张 2:3 竖版悬疑电影概念海报，采用平面丝网印刷语言。暖白纸底，中央是一把朱红色的直背椅子，以严格正面的简洁轮廓呈现。椅子椅背内部的暖白负形形成一个闭合嘴唇的轮廓，这是全图唯一视觉隐喻；嘴唇只是镂空形状，不出现真人面孔。椅子占画面高度约一半，四周大面积留白。下方用黑色端正中文排出唯一片名“静音证词”，四字单行，字距舒展；片名与椅脚之间留出明显间隔。只用暖白、朱红、黑三色，色块边缘清晰，纸张和油墨仅有轻微可见纹理。没有摄影光影、立体渲染、其他文字、人物、血迹或额外悬疑符号。
```

### Banana

```text
生成一张 2:3 竖版悬疑电影概念海报，片名为“静音证词”，使用平面丝网印刷风格。
核心图形：暖白纸底上，中央只有一把朱红色直背椅子，严格正面、简洁轮廓，占画面高度约一半。椅背内部的暖白镂空负形形成闭合嘴唇的轮廓；嘴唇是椅背中的平面负形，不是附加的真人嘴或面孔。全图只用这一处隐喻。
版式：椅子四周保留大面积留白。下方排唯一文字“静音证词”，四个汉字完整准确，黑色端正字形，单行、字距舒展；标题与椅脚之间有清晰间隔。
色彩与媒介：仅暖白、朱红、黑三色，图形为清晰色块，纸张和油墨纹理轻微，不干扰轮廓和阅读。
画面没有其他文字、人物、血迹或额外悬疑符号，不使用摄影布光、立体渲染或景深效果。
```

看图检查：图形能否独立表达主题；负形是否可辨认；四个字是否准确、主次是否明确。若文字出错，保持图形与布局只修正标题；需要交付可编辑排版文件时，将文字另行排版，不声称栅格图中文字可直接编辑。

## 看图后的局部修订

先检查实际图像，再写“保留什么＋改什么＋完成标准”。以下句式必须针对真实结果调整，不代表已经出图或已发现问题。

- KV 留白不足：保持纸带造型、配色与光线，整体向右移动并略缩小，使左侧三分之一没有主体或投影；不改变纸带折面结构。
- 产品反光过亮：保持瓶体结构、位置、液体颜色和背景，降低玻璃正面大块白色反射的强度，保留边缘窄亮线，让瓶内液体与瓶壁重新可辨。
- 场景层次不足：保持机位、建筑和家具位置，降低入口及书架深处亮度，保留窗边主光与台灯局部暖光，恢复由窗边向入口的明暗衰减。
- 海报标题错误：保持红色椅子、负形、留白和背景，只将下方标题修正为四个汉字“静音证词”，黑色单行，维持原字级和位置。

## 同题测试方法

若用户之后授权实际出图，两平台使用同一个 brief、相同参考图与画幅，并约定各自生成数量。比较创意可读性、构图层级、主体准确性、光材质或平面媒介一致性、排版可用性与修订成本。保留失败结果，不能只挑各自最好的一张来宣称流程整体优胜。未经实际出图，不宣称这些提示词已达到某种审美等级。
