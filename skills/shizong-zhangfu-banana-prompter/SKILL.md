# 《失踪的丈夫》Banana 提示词

## 使用场景

当用户要求给《失踪的丈夫》某个镜头、某段镜头、Banana、Banana Pro、9:16、电影帧、强胶片柔化版提示词时使用本 skill。

## 核心原则

1. 每个镜头必须有独立风格，不允许只写一个统一风格后缀。
2. 输出每个镜头时，必须包含：
   - 镜号、景别、焦距光圈。
   - 分镜动作与构图。
   - 该镜头专属空间风格。
   - 该镜头专属灯光脚本。
   - 该镜头专属摄影/镜头质感。
   - 出现人物的人物设定。
   - 禁止项。
3. 画幅固定为 9:16 原生竖屏，2K。不要写成 16:9 裁切。
4. 风格基底是现实主义法治纪实，但每镜的色温、光源、暗部、镜头和氛围要随剧情变化。
5. 所有屏幕、白板、档案、手机短信、资料墙均不可生成清晰可读文字。

## 人物文字设定

按镜头需要简短嵌入，不要把人物设定写成角色设定板。

- 冯探/冯硕：35-40岁中国男性，短黑发，眉眼锋利，深色西装、浅蓝衬衫、深色领带，沉稳克制，法治节目主持人与现场观察者，不是警察。
- 李警官：35-42岁中国男性基层民警，短黑发，方正脸，稳重克制，深色基层制服或执勤夹克，不出现清晰警徽。
- 黄岚：38岁左右中国女性，县城普通家庭气质，偏瘦，低马尾，素颜，哑光自然皮肤，脸色憔悴，浅灰蓝旧外套，深色裤子，旧斜挎包，焦急但克制。
- 刘卫新：40-48岁中国男性，偏瘦，有劳作感，短乱黑发，脸型疲惫，眼神躲闪，旧灰褐工装外套、深色格子衬衫、旧裤、泥鞋、旧包，心虚紧张，非凶狠反派。
- 陈远光：40-50岁中国男性，中等偏壮，粗粝风霜感，短乱发，橄榄绿旧户外马甲或外套、黑T、旧裤、泥鞋、旧背包，普通县城进山男人。

## 工作流程

1. 确认镜号。
2. 查 `references/shot-style-map.md` 中对应镜号的风格卡。
3. 用镜头风格卡写提示词，不使用统一后缀替代镜头风格。
4. 如果用户给了新的风格图或修改意见，优先更新该镜头风格卡，再输出提示词。

## 输出格式

对单镜头：

```markdown
**镜号｜景别｜焦距光圈**
```text
[完整 Banana 提示词]
```
```

对多镜头：

每个镜头单独一段，不合并风格段。
