# 数据、复盘与实验

## 先确认观察到的是什么

以用户提供的数据、导出、截图或授权读取的后台为准。记录账号/系列、post_id/真实链接、发布时间及时区、数据捕获时间、统计窗、流量来源（如有）、内容/封面/标题版本。截图只覆盖可见字段，缺失值为 unavailable，不能填0。

保留原字段名与平台口径；曝光、观看/阅读次数、独立观看人数、主页访问和新增关注不能互换。账号总涨粉不能直接归因于某条笔记；只能在有笔记级归因时报告该笔记贡献。更换标题/封面、付费推广、节假日及分发来源变化要标注。

## 指标只服务当前目标

| 目的 | 可用证据（有数据才用） | 局限 |
| --- | --- | --- |
| 入口吸引 | 曝光、打开/阅读及平台定义的点击率 | 低阅读可能来自低曝光，不能直接断言封面差 |
| 内容价值 | 收藏、分享、实际反馈、平台可用的停留/阅读数据 | 收藏未必代表关注，更不代表商业转化 |
| 系列兴趣 | 笔记归因关注、回访/主页访问、重复讨论 | 账号净涨粉与单篇带来关注口径不同 |
| 专业/商业价值 | 明确的作品用途反馈、有效合作询问及后续进展 | 点赞不等于客户，未核实咨询不等于成交 |

派生指标注明分母、时间窗和单位。收藏/阅读、分享/阅读等可作比较指标，但不冒充平台官方口径；互动事件之和/阅读是事件比率，不是独立用户转化率。只有曝光与打开定义对应且统计窗一致时，才计算相应打开率。分母为零或缺失时为不可计算，不用0%代替。

## 可比性与不确定性

先按相同发布后时长比较，再尽可能控制图文类型、主题、账号阶段和流量来源。结合绝对数与比率；小样本下个位数变化可能大幅改变比例。用本账号近期可比内容建立基线，不引用无来源的“行业合格线”。中位数或分布可减少单个异常高值的影响，但仍需说明样本量。

没有足够曝光/帖子/相同观察窗时，结论是“证据不足，继续观察或做小测试”，不是自动认定账号被限流。观察可分早期和后续窗口，具体时间根据数据可用性与任务目标选择；不是保证达到流量稳定所需的固定小时数，也不会自动创建提醒。

## 从事实到下一步

| 观察 | 可以提出的假设 | 还需检查 / 下一步 |
| --- | --- | --- |
| 曝光与打开都有记录，打开表现弱于可比内容 | 标题/封面入口可能不清楚 | 检查受众来源、封面主读与标题一致性，下一批只改一个入口变量 |
| 打开尚可、后续互动弱 | 内容兑现、受众匹配或观看深度可能不足 | 查看图组递进和实际反馈；缺少停留数据时不能断言“没人看完” |
| 收藏较多、可归因关注较少 | 单篇参考价值较清楚，系列承诺可能不够明确 | 试更清晰的系列延续提示，保留原来的视觉价值 |
| 点赞不多但出现可信的合作询问 | 对商业目标可能有价值 | 跟进用户授权范围内的询盘质量，不能只按点赞淘汰 |
| 一篇大幅偏离近期表现 | 偶然分发、话题、时点或内容因素都可能影响 | 保留异常记录，检查来源，先复现机制再推广到全栏目 |

以上是待验证解释，不是算法诊断规则。每次复盘把事实、解释、反证、缺口和行动分开。

## 实验约定

每次优先验证一个可改变变量：主题类型、封面距离、标题叙述角度、图组信息顺序等。写清假设、保留项、变量、主观察指标、成本/质量限制、可比样本与窗口、继续/调整/停止条件。不要预设一定显著或宣称自然分发下的两篇帖子是严格随机A/B实验。

用户已锁定的系列审美、平台和身份不属于可擅改变量。改变长期定位需具体提案及对应授权；图像制作方案内的小幅包装调整按已有范围执行。

## 复盘成品

输出：

1. 本次覆盖哪些真实帖子、何时采集、哪些数据缺失。
2. 与账号主目标有关的两三条事实，而非逐项抄数。
3. 哪些机制值得保留，哪些只是猜测，哪些内容需要停止或降低投入及理由。
4. 下一批具体选题变化或一个有边界的实验，以及如何判断结果。

把结论回写到当前账号的选题与运营文档，使用已有状态/素材ID；不改其他账号或共享skill规则。无数据时交付“冷启动假设和观察计划”，不得伪造一次数据复盘。
