# 长期栏目编排

## 用户偏好与适用范围

本用户要提前规划未来一个月乃至一年，按规划连续制作，不要想到一个就发一个，也不需要每篇都解释“为什么发”。对已建立的小红书栏目直接沿用审美方向；增长、商业转化和数据诊断仅在需要时加入。规则不覆盖其他影视项目或独立单图请求。

## 四层计划

| 层级 | 内容与精度 | 何时调整 |
| --- | --- | --- |
| 年度 | 12个主题章节，每章的核心空间/异常、情绪、季节变化、与其他月份的边界 | 每月滚动检查；不预先锁死365个画面 |
| 月度 | 下一月每天的post_id、日期、题目、一个主异常、三张图职责、周章节与制作顺序 | 制作前细化；替换有记录，不随机跳题 |
| 周度 | 从月表中选出近期批次、锚图优先次序、审核与修订位置、候补内容 | 按真实产能和完成情况排，不每天重策划 |
| 每日 | 读取具体post_id，继承当篇空间/风格约束，完成图组、审核、文案与授权发布 | 本日必要局部修订，不改全年方向 |

开始日期未指定时可用明确说明的工作假设，所有日期可以整体平移；不把拟发布日写成平台定时发布成功。区分自然月和连续30天：用户要求30天就准确给30行；自然月按当月实际天数，额外一天需明确安排或留作缓冲。

## 叙事与视觉连贯

- 年度有展开：熟悉空间建立气质 → 扩展到公共城市 → 季节/自然变化 → 新空间与尺度 → 有依据的回访。每篇可以独立欣赏，不要求观众追连续剧情。
- 月内用若干小章节连接，避免每天只有一个互不相关的噱头。章节之间通过门、窗、光、水痕、植物等有限视觉母题承接。
- 同一篇根据具体作品选择空间连续或观念关联；三张各自成立并共同深化命题，不把全景、另一机位和细节作为固定配方。人物或物件需要一致时调用对应制作规则。
- 不把所有月份都做成同一种蓝黑夜景，也不机械要求每天不同技法。安静、好奇、温柔、孤独和微妙不安交错安排。

## 去重与备选

选题比较空间、异常机制、关键物件/线索、情绪/光线，以及画面结构和媒介表现。只换标题或道具颜色不算新选题。同一主异常可以跨空间延展，但必须改变观看关系或视觉尺度；连续数篇相似时先调整月表顺序。

`surreal_art` 的持续艺术性要求覆盖所有月份和每一期，制作时继承 xiaohongshu 的长期艺术标准。年度章节除题材之外，规划可探索的视觉语言；月内安排疏密、色彩、尺度与情绪的变化，保持章节内的联系，不为求变化每天随机换画风。不把首篇的构图、配色或一次成功样本扩写为全年模板，也不把未获选择的媒介提案记成已锁定风格。

新灵感进入候选池，不自动替换下一篇。确需替换时保留原post_id与原案，记录新版本、替换原因及对周/月章节的影响；不覆盖已生成或已发布版本。

回访/合集只能引用真实已存在的素材。年度尚未开始时只能写“拟回访”，不能编造最佳作品、用户喜好或全年成果。素材不足时改为新作，明确标识。

## 生产接续与状态

月表的post_id是计划中的稳定关联键，实际素材身份由现有asset-index维护。计划文档可显示“计划 / 制作中 / 待审 / 可用 / 已上传草稿 / 已发布”等人类可读状态，但写入项目状态时使用现有状态管理器的合法词汇，不新增竞争性状态数据库。

每篇先有完整视觉brief与艺术方案检查，再在已获生成授权的范围内制作。需要同场景连续性时先做锚图、完成适用审核，再继承其实际关系制作其余图片；观念关联组按既定图组设计执行。整组审核后整理文案与发布文件。跨篇可以在授权范围内按制作批次工作，但不得混用房间、光源、物件或参考。生成授权的范围按用户请求，不因月表有30行就一次提交90张付费任务；用户暂停生成时继续优化方案，不自动恢复。

每周留出审核修订空间，备选从同章节题库里选。尚未生产的日期过去时标记待顺延，不能标为漏发后自动补发多篇。下一次“继续”先找已有项目、月表和未完成队列，不新建同名项目或从第一天重复出图。

## 保存与交付

按project-folder-director确定的根目录，在docs中保存年度框架、月度日历和执行规则；现有项目优先复用。计划内要说明版本、日期假设、哪些是已确认方向、哪些是制作提案。给用户一个可读入口文件，表格可配CSV供后续工具使用；两者从同一份内容生成以免不一致。

长期规划完成的最低标准：12个月章节（如请求一年）、准确数量的每日选题（如请求30天）、每篇三张的明确职责、周生产安排、去重与滚动规则、真实保存路径。只列12个抽象主题或说“以后每月细化”不算首月计划完成。
