# 小红书运营决策手册

## 已定栏目先做长期编排

已有明确方向时，先按 [长期栏目编排](long-term-planning.md) 完成年/月/周/日计划。以下定位、受众与研究用于用户确实需要的运营问题，不作为开始制作的强制问卷。选题理由可在内部保留，用户可见日历以日期、画面和制作次序为主。

## 需要时完善定位

从当前账号目标出发，不默认把一切内容都变成涨粉号或接单号。用一句话说明“为谁持续提供什么，以及为什么值得回来”。常见目标可以是艺术受众、视觉作品集、创作交流或商业询盘；如目标兼有，标明主次和冲突取舍。

建立可维护的账号简报：当前目标及来源、受众假设、内容承诺、栏目构成、审美边界、可持续产能、可观察的成功证据、需要验证的问题。账号名、简介和置顶结构可以提出具体草案，但未授权时不修改真实账号。

对于本对话已建立的艺术栏目，可使用以下**起步假设**，不当作实际受众画像：

- 内容承诺：持续发现“熟悉空间里无法解释的一件事”，提供视觉想象和情绪体验。
- 候选受众：喜欢空间艺术、梦境影像和情绪摄影的人；影视/设计从业者是否会收藏作灵感，需要数据或反馈验证。
- 辨识度：日常生活痕迹、一个主异常、少量悬念线索、连贯图组。跨日期换场景，保留系列气质。
- 运营目标待明确时，以建立有辨识度的系列和收集受众反馈作为临时工作目标，不虚构商业承诺。

本栏目假设不能迁移到其他小红书账号或原来的一日一镜；以各自简报为准。

《不存在的电影》使用独立栏目承诺：每篇虚构一部从未上映的电影，以一个原创前提、一个核心视觉矛盾和同世界观的海报/壁纸图组建立期待。不要把上面的“熟悉空间异常”假设强加给该系列，也不要把真实电影、客户项目或既有影视日记包装成虚构电影。

## 研究必须有证据

需要对标/受众/搜索研究时，区分三类材料：自己的后台数据、实际看到的公开笔记与评论、创意假设。对公开案例保留链接或可定位ID、查看时间、内容形式、可见指标和可迁移机制。公开点赞不能代替曝光、阅读、收藏、转粉或成交。

选择同题材、同媒介、同内容功能的对照，并说明账号体量和发布时长不一致的限制。不只挑爆款得出“都有效”的结论；也看普通表现的例子。研究标题如何建立期待、封面怎么读、后续图片提供什么、评论实际谈什么，不复制原图、原文或整个栏目。

需要最新趋势或平台规则时检查当前来源；不能访问账号/平台就返回明确的研究缺口和可先执行的创意计划。禁止杜撰小红书算法权重、万能流量密码、必爆发布时间和限流原因。

## 选题不能只靠好看

内部选择候选选题时可检查以下问题，无需每篇向用户解释或等待回答：

| 判断 | 决定什么 |
| --- | --- |
| 与账号承诺一致吗 | 不为热点破坏主线 |
| 受众为什么点开或继续看 | 明确入口期待，而非只有作者自我欣赏 |
| 看完得到什么 | 视觉享受、情绪共鸣、灵感收藏或具体方法，选择真实适用的价值 |
| 与最近几篇有何不同 | 空间、异常、情绪或表达至少有明确变化 |
| 缩略图能读懂吗 | 主体与异常可辨，避免依赖极小文字或复杂细节 |
| 能在产能范围内做好吗 | 图片数量、连续性难度、预计返修和成本合理 |
| 有什么支持这个选择 | 真实反馈、同类表现、研究观察，或明示为创意假设 |

用“优先 / 候补 / 暂缓 + 原因”即可，避免用没有依据的综合分数伪装准确预测。选题库至少保存主题、内容支柱、受众价值、选择依据、与旧内容的差异、制作状态和关联 post_id。

## 排期先保证连贯与可执行

只有长期运营范围适用栏目排期；给一张图不强制建立月计划。已有计划时按实际进度更新，未发布稿不自动算发布过。

每行至少包括：post_id、拟发布日/顺序、章节、题目、具体异常、三张图的信息递进、制作状态。主目的、受众证据和实验指标仅在该任务需要时加入。日期是编排安排，不自动代表平台最佳时段或已设置定时发布。

艺术栏目可以在“自然进入室内 / 城市奇遇 / 未知门窗 / 时间光线异常”之间轮换，并保留少量实验空间；具体频次和比例依据目标、产能与反馈，不固定套用每日七种任务。周末不强迫变成商业广告或教程。

可建议一个小批次启动（例如七篇作为可调整计划），不是一次性生成七套的授权。先用少量已完成作品验证视觉表达与生产负担；每天发一篇是期望，质量、资源和用户当前要求决定实际节奏。

## 封面、标题和正文协同

运营负责人定义内容承诺与标题角度，制作负责人交付成稿与画面。不要出现“标题承诺发现秘密，三张图没有新信息”的落差。

- 封面：检查缩略图主读、异常辨识度、裁切后线索是否还在；不默认强加大字标题破坏艺术图。
- 标题：选择一个清晰的空间/异常/情绪角度；关键词自然描述实际内容，不塞无关热门词，不虚构亲历或真实地点。
- 图组：第一张提出视觉问题，第二张提供新视角，第三张留下可感知的线索；实际画面由制作技能判断。
- 正文：补充一层创作感受或观看线索，不把每处谜底解释完。明确AI视觉创作，避免伪装真实摄影或虚构客户案例。
- 标签：从内容、媒介、受众用途选择少量相关标签；平台当前格式和数量规则在执行时核对。
- 互动：只有确实能引发讨论时才放自然问题，例如“你觉得门后是什么时间？”；不机械要求点赞收藏，也不使用无关诱导。

标题候选是编辑方案，不是已验证胜出版本。封面/标题实验优先安排在后续可比帖子或经授权的版本修订，不能靠无授权重复发布同一帖子测试流量。

## 运营检查与艺术审核的区别

艺术审核判断图像、风格和连续性是否完成；运营检查判断内容承诺、受众价值、系列辨识度及图文匹配是否清楚。两者分别留下结论。

运营检查可以提出“异常在缩略图中不清楚”“标题暗示真实经历”“三张没有新增信息”等可修问题；不能以未经验证的“可能不爆”否决符合目标的作品。没有账号数据不阻断合格的冷启动内容，也不能把运营检查通过解释为流量保证。

## 评论反馈与商业意图

用户要求分析反馈时，将实际评论分成情绪共鸣、世界观猜测、制作方法、收藏用途、授权/合作询问等，列出具体例子与观察局限；单条评论不是整体受众结论。

有商业目标时可以准备作品集组织、能力说明、合作问题清单和回复草案。询盘记录只保留必要信息并明确来源；不把赞美评论当成有效客户，不编造作品授权、报价或合作结果。发送评论、私信、商务外联和真实账号资料修改须有相应授权。
