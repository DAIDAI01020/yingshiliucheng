# KV Reference Library

Use this reference when `$kv-director` needs professional commercial/event key visual logic. It is not a list of layouts to copy. Translate each reference family into communication hierarchy, title/logo/sponsor-safe composition, subject scale, negative space, extension ratios, material truth, screen readability, and AI generation risks.

This category/reference library is used after `kv-composition-style-library.md`. The composition/style library decides the visual system; this file supplies market, category, and communication mechanisms that refine it.

For LED, stage-screen, large-screen, ultra-wide, wraparound, irregular-screen, or multi-screen KV, this file is not sufficient by itself. Also read `large-screen-kv-experience-library.md` for physical screen systems, stage relation, camera/audience readability, failure controls, and expanded style families.

## Usage Rule

Choose one primary KV reference mechanism and, if needed, one supporting mechanism. Do not stack many KV styles.

For every KV direction, translate the reference into:

```text
kv_type
brand_or_event_claim
core_visual_hook
subject_hierarchy
kv_composition_style_packet
kv_composition_mode
composition_reference_source
reference_mechanism_translation
master_kv_layout_spec
led_screen_layout_spec
safe_area_map
extension_crop_map
layout_safe_area
title_logo_sponsor_zones
main_ratio and extension_ratios
asset_split
AI text/logo/sponsor risk control
post typography plan
```

Do not ask image models to generate final readable typography, logos, slogans, sponsor marks, QR codes, dates, or legal text. Generate no-text base art and add all readable information in post layout.

## Main KV vs Big-Screen KV

Do not treat `主KV` and `大屏KV` as the same canvas.

| Deliverable | Must decide |
| --- | --- |
| 主KV / master key visual | main ratio, subject hierarchy, title/logo/sponsor zones, negative space, crop margins, post typography plan |
| 大屏KV / LED / stage screen | actual screen ratio, center safe zone, presenter/performance safe area, far-distance readability, side extension, whether title appears on screen or in external layout |
| 延展物料 | how 16:9, 9:16, 4:5, 1:1, ultra-wide preserve the same visual DNA without moving key subjects to unsafe edges |

## CCTV / National Media KV

Use this family when the user asks for 中国央视海报、央视风、国家级媒体主视觉、公益宣传、纪录片频道、春晚/大型晚会、时代主题、城市/文化/社会价值传播, or when the KV needs official clarity and public-service authority.

Do not copy the CCTV logo, channel id, title treatment, exact typography, studio package, host likeness, or distinctive program layout. Borrow only the communication mechanism.

| Reference mechanism | Best use | Transferable logic | Prompt translation |
| --- | --- | --- | --- |
| CCTV public-service poster | public value, civic theme, policy-adjacent campaign | dignified central symbol, clean message zone, trustworthy human scale | one strong cultural/social symbol, restrained composition, clean top or side title field, real environment texture |
| CCTV documentary key visual | culture, city, history, nature, people story | factual dignity, location truth, quiet image metaphor | real landscape or human subject, natural light, restrained color, negative space for title |
| CCTV gala/festival KV | Spring Festival, gala, ceremony, cultural celebration | ceremonial center, warm national festival atmosphere, high readability | central stage/object/light axis, broad simple forms, red/gold used with restraint, title/sponsor zones clean |
| National event broadcast KV | major event, forum, commemorative theme | official order, axial composition, monumental scale | symmetrical or center-axis composition, architecture/flag-like rhythm without fake official marks, large clean title zone |

Avoid:

```text
copying CCTV logo, fake official seal, fake national emblem, unreadable Chinese title, over-red-and-gold template, propaganda cliche, plastic CG lanterns, crowded host collage
```
