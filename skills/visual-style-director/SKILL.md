# Visual Style Director

## Scope

Use for initial visual-direction recommendations when no approved system exists. `$style-reference-director` owns reference selection, `$style-bible-director` consolidates continuity, and `$project-style-lock` freezes approved variables. Do not restart these stages or overwrite their decisions. Select photographic, graphic, product, typography, or stage controls according to the deliverable; camera and realism fields are conditional.

## Process

1. Read the script, storyboard, or brief and infer its natural visual temperament.
2. Recommend one main visual style before offering alternatives.
3. Translate strategy and concept into visible cinematic choices.
4. Define tone, color, camera, lighting, material, motion, and composition.
5. State what to avoid so AI outputs stay on-brand.
6. For LED or stage visuals, include readability and scale notes.

## Style inference

Use these signals:

- 稿件关键词：科技、温暖、突破、年轻、高能、城市、人物、产品、舞台、未来、纪实。
- 文案语气：理性说明、情绪叙事、热血号召、幽默娱乐、仪式宣告、产品卖点。
- 节奏：慢速铺陈、快切卡点、冲突悬念、宏大递进、生活流。
- 观看场景：电视、发布会、LED大屏、社媒、展厅、客户提案。
- 受众：年轻大众、家庭、商务、政府/城市、节目观众、高端消费。

Recommend one of these style families or a hybrid:

- 高端商业电影感：适合TVC、品牌、产品、科技和高端消费。
- 情绪叙事电影感：适合品牌片、城市片、人物故事、温暖或价值表达。
- 纪实人文质感：适合真实人物、社会议题、城市生活、公益和可信表达。
- 科技未来视觉：适合发布会、科技品牌、汽车、新能源、数字产业。
- 节目包装高能感：适合综艺、栏目预告、人物看点、赛制冲突。
- 仪式开场大片感：适合发布会、盛典、论坛、晚会开场。
- 沉浸式大屏视觉：适合LED、舞美、展厅、宽屏/异形屏。
