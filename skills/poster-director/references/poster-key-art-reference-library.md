# Poster / Key Art Reference Library

Use this reference when `$poster-director` needs professional poster, key art, KV, social cover, or thumbnail logic. It is not a list of layouts to copy. Translate each reference family into communication hierarchy, title-safe composition, subject scale, negative space, symbol use, and AI generation risks.

## Usage Rule

Choose one primary poster reference mechanism and, if needed, one supporting mechanism. Do not stack many poster styles.

For every poster direction, translate the reference into:

```text
poster_type
core_hook
subject_hierarchy
layout_safe_area
title/logo safe zone
visual_symbol
color/material boundary
asset_split
AI text/logo risk control
```

Do not ask image models to generate final readable typography. Generate no-text base art and add title/logo/cast/slogan in post layout.

## Short Drama / Platform Cover

| Reference mechanism | Best use | Transferable logic | Prompt translation |
| --- | --- | --- | --- |
| Vertical short-drama platform cover | revenge, romance, family conflict, suspense hooks | large readable face, one conflict object, simple background, high crop safety | 9:16 no-text cover base, face in middle third, clean title band, one symbolic prop, no AI text |
| Suspense evidence cover | missing person, crime, case clue | human face + evidence object + negative space | character face partially shadowed, evidence/photo/phone as foreground symbol, dark clean title area |
| Relationship triangle cover | romance, betrayal, family ethics | character hierarchy and eye-line tension | one lead largest, second character behind/side, distance and gaze encode conflict, clean lower title zone |
| Revenge/identity reveal cover | comeback, secret identity, reversal | split identity, mirrored posture, strong central silhouette | central character with controlled dual-world background, no literal text, title-safe top/bottom band |

Avoid:

```text
cheap platform template, beauty-filter skin, random red/blue suspense gradient, crowded cast, fake luxury, unreadable generated Chinese title
```

## Poster Translation Checklist

Before handing to `$frame-vision-director`, ensure the poster reference has been translated into:

```text
one primary reference mechanism
poster_type
core_hook
subject_hierarchy
layout_safe_area
main_ratio and extension_ratios
no-text base art plan
asset_split
AI risk controls
post typography plan
```

If any of these are missing, the poster direction is not ready for final image prompts.
